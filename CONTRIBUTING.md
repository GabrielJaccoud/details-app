# Como Contribuir para o Projeto Details

Bem-vindo(a) ao projeto Details! Agradecemos o seu interesse em contribuir.

## Como Começar

1.  **Fork** o repositório.
2.  **Clone** o seu fork localmente.
3.  Crie uma **branch** para a sua feature ou correção de bug: `git checkout -b feature/minha-nova-feature`.
4.  Faça as suas alterações e **commit** com mensagens claras e descritivas.
5.  Envie as suas alterações para o seu fork: `git push origin feature/minha-nova-feature`.
6.  Abra um **Pull Request** para a branch `main` do repositório original.

## Diretrizes de Código

-   Siga os padrões de código existentes no projeto.
-   Escreva testes para as suas alterações, quando aplicável.
-   Garanta que todos os testes passem antes de submeter um Pull Request.

## Relatando Bugs

Se você encontrar um bug, por favor, abra uma `Issue` no GitHub com as seguintes informações:

-   Descrição clara e concisa do bug.
-   Passos para reproduzir o bug.
-   Comportamento esperado vs. comportamento atual.
-   Capturas de tela ou logs, se relevantes.

## Sugerindo Novas Funcionalidades

Para sugerir uma nova funcionalidade, abra uma `Issue` no GitHub descrevendo a sua ideia e o problema que ela resolve.

Obrigado(a) por contribuir!
